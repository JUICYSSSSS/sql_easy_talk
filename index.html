Academia SQL

Aprende los conceptos fundamentales de Compiladores aplicados a nuestro Traductor de SQL.

🔍

1. Análisis Léxico (Tokens)

El Lexer toma la frase que escribes y la divide en componentes fundamentales (Tokens) usando un Autómata Finito Determinista.

Expresiones regulares definidas:

• Acción (SELECT_KW):
  \b(mostrar|ver|listar)\b

• Condición (WHERE_KW):
  \b(con|donde|que)\b

• Operador (OPERATOR):
  \b(mayor a|menor a|igual a)\b

• Entidad (ENTITY):
  \b[a-zA-Z_][a-zA-Z0-9_]*\b

• Número (NUMBER):
  \d+
🌳

2. Análisis Sintáctico (Parser)

El Parser usa Descenso Recursivo para asegurar que los Tokens tengan sentido gramatical según la CFG.

Gramática Libre de Contexto (CFG):

<Statement> →
  SELECT_KW  ENTITY
  [ WHERE_KW  ENTITY  OPERATOR  NUMBER ]

Ejemplo válido:
  "mostrar clientes con edad mayor a 30"
🔄

3. Generación de Código

El Translator convierte los componentes validados en una consulta SQL real, adaptada al dialecto seleccionado.

Dialectos soportados:

• MySQL:
  SELECT * FROM entidad
  WHERE atributo > valor;

• SQL Server:
  SELECT * FROM [entidad]
  WHERE [atributo] > valor;
⚙️

4. Guía de Motores (RDBMS)

Los sistemas gestores de bases de datos más populares difieren en su sintaxis y capacidades.

• MySQL — Popular en la web, open-source
• PostgreSQL — El más avanzado, ANSI SQL
• SQL Server — Microsoft, T-SQL
